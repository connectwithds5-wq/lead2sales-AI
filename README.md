# Lead2Sales AI

Fresh MVP for CCTV/security-system dealers to capture leads, structure requirements, create quotations, and follow up without losing opportunities.

## Product principle
Sell the outcome, not the software: help businesses recover missed leads and convert more enquiries.

## MVP roadmap
- Initial sales command center UI
- Lead capture and search
- Supabase persistence
- Authentication and multi-tenant companies
- CCTV requirement analyzer
- Product/pricing catalog
- BOQ generator
- PDF quotation
- WhatsApp follow-up
- Analytics
- Billing

## Local development
npm install
npm run dev
